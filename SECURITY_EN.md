# Security Policy

## Supported Versions

Only the latest version is supported.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it through one of the following methods:

- **GitHub Security Advisories** (recommended): Use the "Report a vulnerability" button on the Security tab of this repository.
- **GitHub Issues**: For non-sensitive security issues, you may open a regular issue.

Please do **not** disclose vulnerability details in public issues.

We will review the report and respond as soon as possible.
